## HBAO Shader 代码审查（Shaders/Shaders_For_HBAO.hlsl）

对 `Shaders/Shaders_For_HBAO.hlsl`（204 行，`VSMain` / `PSMain_HBAO` / `PSMain_Blur`）
及配套 `Passes/HBAOPass.h`、`Graphics/PipelineManager.h:918+`、`PBR_Render.cpp:1383-1563`
做了完整通读，结论如下（供后续修改参考）。

### 已确认正确的部分
- 矩阵约定一致：项目统一采用行向量 `mul(rowVec, M)`；CPU 侧上传前做了 `XMMatrixTranspose`
  （`PBR_Render.cpp:515-521`），恰好抵消 HLSL cbuffer 默认 column_major 布局，
  因此 `mul(clipSpace, invProjMat)` 与 `mul(worldNormal, (float3x3)viewMat)` 正确。
- cbuffer 布局与 C++ `HBAOConstants`（`Passes/RenderStructs.h:76`）字段偏移一致；
  HLSL 侧 224B / C++ 侧 256B 的体积差异无害（根 CBV 无尺寸限制）。
- 深度约定为**标准 Z**（非 reverse-Z）：DepthFunc = LESS，clear = 1.0，
  故 `HBAO_BACKGROUND_DEPTH = 0.999999f` 判定合法。
- 水平线积分逻辑正确：`maxAngle` 在 i 循环内、j 循环外初始化，
  单调更新 + `(currentAngle - maxAngle)` 增量符合标准 HBAO。
- `temporalFrameIndex & 7` 的 8 相位旋转与 `ScalarTemporalFilterPass` 的下游使用一致。

### 待改进项（按优先级）
1. **P1 采样步长忽略投影参数**：`stepSizeUV = radius / P.z / numSteps` 仅在
   `proj[0][0] == proj[1][1] == 1` 时成立。本项目 FOV_y = 45°(可调 1~45)、16:9 下
   P11 = 2.414、P00 = 1.358，真实步长应为 `radius * P00 / (2 * P.z * numSteps)`（U 轴）
   与 `radius * P11 / (2 * P.z * numSteps)`（V 轴）。当前实现造成 U/V 各向异性约 1.78×。
2. **P1 clamp [0.001, 0.05] 与 radius 语义脱节**：1080p 下 0.05 = 96 px/步 × 4 步 = 384 px，
   远超 radius 覆盖范围（样本被 `dist < radius` 丢弃，纯浪费）；近距离 0.001 = 2 px/步，
   又严重欠采样。改为由投影推导可同时消除该 clamp。
3. **P2 模糊权重使用非线性深度**：`exp(-abs(centerDepth - sampleDepth) * 100.0f)`，
   near = 0.1 / far = 1000 时深度分布极不均匀 —— 近处相邻像素深度差大（权重被压到 0，
   近景残留噪声），远处深度差 ~1e-5（边缘检测失效，跨轮廓渗色）。建议线性化到视空间 Z。
4. **P2 模糊开销**：25 tap × (2×exp + pow(dot,16))；raw AO 为 R16_FLOAT，
   可改用 Gather/GatherRed 把 tap 降到 ~9，或缩小核。
5. **P2 `Rand()` 哈希质量**：`frac(sin(dot(co, c)) * 43758.5453)` 易产生条带；
   仅 8 个相位 → 有效独立样本上限为 8，超过后方差不再下降。建议换 PCG/整数哈希。
6. **P3 微优化**：`offsetUV` 越界判断可用 `break` 替代 `continue`（步进单调）；
   `normalize(DecodeGBufferNormal(...))` 归一化冗余（随后又 normalize 一次）。
7. **P3 设计备注**：`Shaders_For_Deferred.hlsl:137` 用 `min(ao, hbao)` 合并两套 AO，
   非能量守恒，重叠区会比任一单独结果更暗 —— 建议确认为有意为之。

## Bindless 纹理绑定链路（RDG → 根常量 → HLSL）

本项目**不使用** `register(t0)` 常规绑定，而是通过 bindless 描述符索引传递纹理。
链路共 4 跳，权威定义点全部在 `Passes/HBAOPass.h` 的 `AddToGraph()`：

1. `graph.CreateTexture(...)` 建瞬态纹理（HBAOPass.h:152 `HBAORaw`）
2. 对**同一张资源**分别建 SRV / RTV 两个视图（HBAOPass.h:178-179）
3. 用 `RDGPassParameters.WriteRTV/ReadSRV` 声明读写，RDG 据此自动建 pass 依赖
   + 插入 TRANSITION 屏障（HBAOPass.h:195 / 220；屏障由 RDG 的
   `BuildBarrierPlan`/`SubmitBarriers` 负责，故执行函数名为 `*NoBarrier`）
4. `SetGraphicsRoot32BitConstants(1, 4, {srvIdx, depthIdx, normalIdx, 0}, 0)`
   （HBAOPass.h:114-115）→ HLSL `cbuffer BindlessIndices : register(b1)` → `texIdx0`

关键结构约定：
- 根签名参数 1 必须是 `D3D12_ROOT_PARAMETER_TYPE_32BIT_CONSTANTS`（ShaderRegister=1,
  Num32BitValues=4），见 `Graphics/PipelineManager.h:927-931`。
- 必须带 `D3D12_ROOT_SIGNATURE_FLAG_CBV_SRV_UAV_HEAP_DIRECTLY_INDEXED`
  （PipelineManager.h:958），否则 `ResourceDescriptorHeap[...]` 无法工作。
- `descriptorIndex` 由 `ResourceManager::AllocateTransientSrvUavDescriptor`
  （ResourceManager.h:947-967）按帧从 `mainDescriptorHeap` 分段分配，
  即 `srvIdx` 自增；该堆同时用于 `SetDescriptorHeaps`。**索引逐帧变化，不可跨帧缓存。**
- raw 与 blur 两个 PSO 共用同一个根签名，仅传入的参数值不同。
- `RDG::AddPassDependency` 内部去重（RDG.h:2358-2364），因此
  `PBR_Render.cpp:1405-1406` 的显式依赖是冗余但无害的。
