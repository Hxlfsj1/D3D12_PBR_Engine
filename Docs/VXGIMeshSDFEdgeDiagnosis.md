# Mesh SDF 白色条块：三个机位诊断

**公开实现核查补充：** 后续查阅Epic讲稿及AMD/Godot源码，确认容差命中本身是
常见的距离场近似，并非普遍要求最终验证原始三角形。下文的伪命中指与原三角形
参考不一致、且在本工程中导致亮条的近表面命中；不能据此将“三角形确认”
当作唯一修法。修正后的判断和资料见[公开实现核查](VXGIMeshSDFTracingReferenceReview.md)。

2026-11-03。三个截图机位均已复现。**主要问题是近段 unsigned Mesh SDF 的
阈值接近判定被直接当成几何命中，尤其在墙角产生距离 0 的伪命中；随后 SH
取光把该错误变成亮条。** 室外探针参与插值会进一步放大亮度，不能解释全部条带。

本轮仅诊断。正式 shader、模型、配置与可执行程序保持原状；所有控制 shader
在 `tmp/vxgi-mesh-edge/` 的独立副本中。没有推广三角形参考为生产路径或作性能承诺。

## 命中语义问题

源码链路：

1. `Shaders/SSGIHybridCommon.hlsli:32` 设置命中阈值为 0.9 个局部 SDF cell；
   原 Cornell 实例缩放1、cell=0.1，对应 **0.09 世界单位**。
2. 接收点沿几何法线偏移约 **0.099**，使起点离开自身面的阈值范围。
   但靠近交线时，起点仍可能离相邻墙/顶面不足阈值；同一个偏移不能同时保证
   离开所有相邻面的近表面区域。
3. `Shaders/VXGISDFThresholdCommon.hlsli:187` 只判断插值场值
   `sample.distance <= threshold` 就返回 `VXGI_THRESHOLD_HIT`。它不要求
   射线实际穿过三角形，也不检查射线正在靠近还是离开邻面。
   当第一次采样就满足条件时，返回的射线距离是 **0**。
4. `SSGIHybridCommon.hlsli:449` 和共享近段路径
   `Shaders_For_SSGI.hlsl:632` 立即在这个近表面位置查询 raw SH，把它当作
   命中表面的光照。于是墙角处许多出射方向都在起点结束，改变了本应查询的
   真实表面位置、遮挡和辐射来源。

这是运行时阈值查询的问题，和烘焙太阳光自命中过滤使用的 0.0001 `tMin`
不是同一条路径。降低那个烘焙 `tMin` 无法确认这里的几何交点。

## 原生 CPU 见证

`tmp/vxgi-mesh-edge/witness.cpp` 使用工程自己的 `VXGIMeshSDFCache`、
`VXGISDFThreshold::TraceLocal` 和 `VXGISDF::TraceReference`，读取从原Cornell
glTF节点变换恢复的44个三角形，格距0.1，无窗口或GPU构造。它是CPU参考见证，
不是从截图对应GPU射线队列逐条读回的计数。

- 接收点：`(1.95,3.8,-2.02536249)`，后墙几何法线朝+Z。
- 偏移后起点：`(1.95,3.8,-1.92636251)`，离自身后墙约0.099，离邻墙约0.05。
- 起点插值场值：**0.04016004**，小于阈值0.09。
- 方向 `(-1,0,0.25)`：原三角形在2米内 **MISS**；阈值查询第1次采样返回
  **HIT，distance=0**。
- 反向X的方向 `(1,0,0.25)`：真实邻墙命中距离约 **0.05153877**；阈值查询
  仍返回 **HIT，distance=0**。

两个方向具有正的接收面法线分量，均可出现在该面的漫反射半球内。
见证说明：近表面距离不能直接代表沿射线的交点距离；简单丢弃所有这种命中
也会把后一种真实遮挡与合法取光一起丢掉。

## 修复边界与产物

优先修复“阈值候选 → 确认命中 → SH取光”的语义，使接近表面不直接产生
虚假的发光/取光表面，同时保留真实遮挡。不能只扩大起点偏移、屏蔽零距离
或继续压烘焙 `tMin`；这些手段没有确认交点。
三角形参考用于定位，本轮没有将其运行成本作为生产方案验收。
逐贡献探针的可见性约束属于另一层，仍需独立处理。

九次 Debug 隐藏运行均完整退出、D3D12 warning/error为零、验证层可用。
CPU见证以工程原生头文件 `/O2 /W4 /WX` 编译并运行通过。
没有修改生产算法、射线预算或正式配置，也没有重新做FPS结论。

数据：`tmp/vxgi-mesh-edge/analysis.json`、`fixture.json`、`cpu-witness.json`，
三个基线、三个近段三角形参考及机位1另外三项对照的 `runs`/`Captures`。
分析命令：`python Tests/AnalyzeVXGIMeshEdges.py`。
