# Cornell Box：VXGI 漏光测试方案

日期：2026-11-02。状态：方案；本轮只检查资产、配置和生产取光/抓帧接口，尚未执行本方案或修改渲染算法。

## 目标

回答三个问题：当前场景有没有可确认的 VXGI 漏光；漏光发生在几何求交、探针缓存消费还是最终重建；Mesh SDF 近段与 Global SDF 远段分别有什么责任。

先完成可证伪的零能量测试，再讨论原场景的观感。红绿墙的正常颜色反弹、入口合法进光和阴影暗部有间接光，均不能直接判为漏光。

## 已检查的工程事实

- `Settings/Scene.json` 使用 `Models/Cornell_Box.glb`，平移 `(0,0.01,0)`，另有缩放后的 `Plain.glb`。
- Cornell GLB 共 12 个几何 mesh、44 个三角形，无纹理。墙、地面和天花板都是零厚度面片；房间法线朝内。两块内部方块为盒形网格。
- GLB 原坐标范围约 X=[-2,2]、Y=[0,3.971]、Z=[-2.025,2.025]；正面开口位于原 Z=-2.025，开口约 X=[-1.703,1.703]、Y=[0.297,3.674]。引擎导入使用 MakeLeftHanded/FlipWindingOrder，前方开口对应引擎 Z 正侧；相机与 ROI 最终以运行时几何核对。
- 顶灯位于原 Y=3.965，离天花板约 0.0058；材质 emissiveStrength=38，所有资产材质 doubleSided=true。GI 源自发光另在 `GISourceCommon.hlsli` 按峰值限到 2，不能拿可见灯面亮度直接当 GI 输入能量。
- Cornell 实例当前 `is_cutout=true`，资产无 alpha 纹理，baseColor alpha=1；先确认覆盖恒为不透明，不能将分类标记直接当成存在透明洞。
- 当前还有方向光和强度 0.1 的环境光；正常合成包含这些贡献。原场景不满足“盒内应该全黑”的条件。
- 当前探针格距 0.5，padding=1，Mesh SDF 格距 0.1；世界近/远采样 16/64，每轴追踪缩小 2。冻结这些设置作为本轮基线。
- 世界命中在 `SSGIHybridCommon.hlsli` 查询八邻 raw SH，生产查询没有逐探针可见性验证；无支持返回零，存在支持时重新归一。先测这些机制，不预先认定它们就是当前画面主因。

## 测试场景与对照

所有派生资产和设置放入独立 `tmp/vxgi-cornell-leak/runtime/`，隐藏运行生产程序。原模型、正式 Scene/Lighting/Pipeline 和当前用户修改保持原样。测试资产保留生成脚本及输入哈希。

### A：当前开口 Cornell，观察组

保留当前模型、Plain、顶灯和灯光，固定入口总览、内侧后墙/墙角、方块接触区三个机位。保存正常合成、纯 GI 和 GBuffer，标注可疑区域。

这组用于对应用户看到的现象，不对暗部亮度设零阈值，也不以红绿串色本身判断漏光。另存 Deferred/BounceSource，检查直射阴影错误是否已经进入 GI 源。

### B：封口 Cornell，外部光源的零能量测试（主测试）

在副本中只封闭正面真实开口，保留原有零厚度墙；去除额外 Plain，关闭内部顶灯、方向光和环境照明。加入独立的盒外自发光面，贴近一面完整墙的外侧但不相交，使用已知有限发光强度，保持生产自发光限幅规则。

封口面并入 Cornell 副本的同一模型资产，避免新增封口实例改变近段最近两个模型的候选预算。先检查封口、墙面连接、双面遮挡、法线和三角形引用；不得留缝，也不得把相机放进墙或封口面。源面位置、朝向和功率写入 fixture，保证外侧探针能够实际采到该光源。

同一几何分别运行：

| 用例 | 盒外发光面 | 盒内合法输入 | 作用 |
| --- | --- | --- | --- |
| B0 | 发光为零，几何保留 | 零 | 黑电平、残留历史和基线噪声 |
| B1 | 开启 | 零 | 若盒内出现稳定的源相关能量，确认漏光 |
| B2 | 开启，在测试副本打开一处受控窗口 | 非零 | 正对照，证明发光、有效探针和测量链路确实工作 |

B0/B1 各自重新初始化并完成探针填充，不能沿用错误的光照历史。B2 除窗口外保持与 B1 一致。若 B1 全黑但外部探针根本没采到光，或 B2 不能响应，本轮判为测试无效，不能判通过。

室内相机看向靠近盒外光源的墙内侧，同时覆盖墙角、顶/地接缝与靠墙方块。使用几何定义 ROI，边界单列；主 ROI 排除轮廓和开口窗口。

这组的物理预期来自完整遮挡与零内部光源，不要求实现具有多次反弹。即使是单层双面遮挡片，理想不透光表面也应阻断穿墙能量；其 SDF 表示能力由后续分层结果解释。

### C：单变量定位（仅 B1 失败后展开）

1. **几何层**：对穿越墙面、掠射墙角和原生产偏移后起点的有限射线，比较 CPU 世界三角形参考与当前 Mesh SDF 阈值查询。区分漏命中、提前命中/零距离命中、耗尽和非法；纳入原点偏移越墙检测。参考处理与生产相同的不透明/双面规则。
2. **探针层**：记录命中位置、八邻探针的坐标/状态/SH/权重，以及各贡献探针至命中点的三角形参考可见性。用诊断副本额外拒绝被墙挡住的贡献者，与同一 raw 缓存的原查询对照。它是归因控制，不作为正式修复。
3. **重建层**：比较新鲜射线结果、owner gather/Repair 后、时空降噪后和最终 HDR；定位原始样本正确但重建后跨墙混光的情况。
4. **模型厚度**：前述定位完成后，在保持内表面位置、材料与光源不变的副本中，仅向外增加壁厚，比较 0 与 0.2 世界单位；记录探针分配变化。它验证薄片敏感性，不能把加厚后通过写成原模型通过。

不在首轮同时改格距、偏移、射线数、滤波和墙厚。只有结果指向某个尺度问题时，才增加对应的单参数实验。

## 如何拆分 SSGI、近段与远段

每个有效场景固定机位与采样序列，分别采集已有三个入口：

- `--pass-gi-source=ssgi`：屏幕贡献；
- `--pass-gi-source=mesh-sdf`：屏幕加近段 Mesh SDF；
- `--pass-gi-source=default`：完整屏幕、近段和 Global SDF 远段。

这些入口是累计来源，不存在现成的“纯 VXGI”菜单。三个最终画面有各自历史和非线性处理，禁止直接相减后声称得到精确的 VXGI 能量。

确切归因需要在测试副本中导出同一次 Trace 的 screen/near/far 线性贡献，并记录实际查询/命中数量。必须验证有进入 2–8 世界单位的有效远段且在 clipmap 覆盖内；未触发远段的机位只验证近段，必要时在同一 Cornell 资产内增加一处固定机位。

## 输出、预热和度量

- 首轮采用 1280×800、AA=None、HBAO 关闭、曝光固定；保持 GI 自身的时空滤波启用。完成归因后，仅对异常用例恢复当前 DLSS 配置复核观感。
- 每次启动确认探针初始化完成、有效记录达到配置的 32 次成功更新；分别记录有效/禁用/失败数。填充不完整不能用来宣称不漏光。
- 相机静止后先预热 128 个实际渲染帧，保存 160/192/224/256 帧及相同采样序列的 B0/B1；尾段仍不稳定则延长并记录，不仅凭“跑满固定帧数”判收敛。
- 保存所有 fixture、配置、相机、源码/资产/可执行哈希、分辨率、历史有效状态、随机序列和 D3D12 检查结果。相机朝向采用引擎 Y-up，不借用旧汽车机位。
- **现有导出不足之处**：纯 GI output 的 raw 是经过 AA/ToneMap 的 RGBA8，GI accumulated HDR 是累计场景。需增加测试专用的线性 `E/pi` HDR 读回，以及所需的分层诊断；现有 PNG 用作目视检查，不能拿它计算漏光能量。测试结束不向编辑器增加常驻控件。
- 主 ROI 报告 B1−B0 的线性亮度均值/P95/max、正差像素比例、连续亮区面积和尾段波动；输出同曝光 PNG、固定标尺热图及 ROI 图。明暗边界、无支持区、非法/耗尽区分别标注，不能把黑洞当良好遮挡。
- 采用预先记录的零检验门槛：`epsilon=max(1e-5 E/pi, 5×B0尾段噪声估计)`。该值是本实验的检出门槛，不是通用画质标准。报告原始数值和源强；不得观察结果后放宽 epsilon。
- 零能量用例中，非有限值立即失败；稳定均值差超 epsilon 或稳定的连续正差亮区（至少 4 个相邻 GI 像素）触发漏光定位。孤立异常也保留并复查，不能用 P95 掩盖小接缝漏光。

## 交付与结论边界

产物放 `tmp/vxgi-cornell-leak/`，正式结论写入 `Docs/VXGICornellLeakTestReport.md`：列出原场景现象、B0/B1/B2 有效性、近/远分层证据和原因；附实际图像及可复现命令。

首轮只做 A、B 和必要导出。B1 失败再执行 C 对应分支。除一次受控诊断外不展开性能优化，不直接调整正式算法。

通过的表述限定为“该几何、光源位置、机位、配置及检出阈值下未检出漏光”。失败区分几何漏遮挡、探针跨墙取光、源污染、重建混光；允许多因共存。当前开口模型的整体 GI 准确度与多次反弹质量不由零能量测试单独保证。
