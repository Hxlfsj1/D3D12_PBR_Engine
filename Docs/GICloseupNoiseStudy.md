# 近处 GI 噪声对照与方案

2026-11-04。按用户新提供的两个机位复现，所有调参和原型都在 `tmp/gi-closeup/`；**没有把试验参数或着色器合入主工程**。结束时核对了 69 个主工程设置/着色器/相关源码文件的 SHA256，均与开始时一致。

现用配置完整保留：降采样 8、world 近/远预算 32/128、近处距离 2.0/2.2 m、owner 积累 4、world 空间滤波间距 2、DLSS Quality、HBAO 开启。Pipeline SHA256 为 `32a5b97baae4abd0d1b92df279d9d1a87fe737c43a55934efe6eb1dec66b1591`。

## 结论与建议

近处有两个因素叠加：

1. 进入近处质量档后，共享块由 4×4 变成 2×2，方向预算从远处的 128 切为 32。更细的空间布点伴随着较少的方向样本，不能把这个档位简单理解为所有质量都更高。
2. 当前滤波半径按 GI 像素固定。同样的屏幕范围，在近处覆盖更小的实际墙面，因而对世界空间照明起伏的平均更弱。

图二的深度导出显示：GI 采样点距离的 5%/中位/95% 分位约为 1.79/1.93/2.29 m，67.4% 在 2 m 以内。实际共享块策略还受父块内其他接收点及滞回影响，不能把这个比例直接当成精确的近档块占比。该机位 screen SSGI 的导出为零，不能指望它补掉这里的 world 噪声。

建议的正式方向是 **保留降采样 8，补近处的方向样本，并仅在近处适当扩大 world 显示滤波范围**。初始质量档可试近处 128；远处 128 及远景滤波维持现状。滤波原型采用距离不超过 1.5 m 时的间距 4、超过 2.5 m 时的间距 2，中间平滑混合，避免硬切。

近处 128 + 全局间距 4 的静态组合已经测过；近处专用滤波原型也分别测了两个机位。**两者合成的正式自适应版本尚未合入，也未完成运动和接触阴影的验证**，不把组件试验当成完整生产结论。

## 如何测量

截图机位按位置/Euler 四位小数重建，FOV 45°：

- 图一：位置 `(-1.8789, 2.0916, 6.2368)`，旋转 `(2.75, 162.25, 0)`。
- 图二：位置 `(0.2221, 2.3302, 0.3074)`，旋转 `(-4, 83.75, 0)`。

模型、场景和灯光与当前设置相同。控制测试为 1706×1066、AA=None、HBAO 关闭，约对应 2560×1600 DLSS Quality 的内部尺寸，但没有模拟 DLSS 重建，不能当作实际桌面帧率测量。主工程相关配置没有被覆盖。

12 组连续序列，每组 291 帧，捕获 256–287 帧，合计 384 帧；另做一次几何/探针数据单次捕获和两次正常合成画面捕获。各近处候选的相机序列逐帧一致。使用从当前源码独立构建的诊断程序，仅连续读回 filtered GI，避免之前首帧同时捕获所有 owner 资源和探针的连续抓帧干扰；单次完整捕获与最小序列的第 256 帧 RGB RMSE 约 `7.29e-6`。

高预算对照为近处 512、远处 128，其 32 帧均值仍有噪声，且共享同一套探针/低阶表示，**不是物理真值**。表中 RGB 距离为各候选 32 帧对该均值的合计 RMS，取中心区域（宽度约 10%–90%、高度约 10%–90%）。降采样 16 的输出先重采样到相同屏幕网格再比较。

## 图二结果

| 试验 | 对高预算均值的 RGB 距离 | 时间波动 RMS | GPU 中位数 |
|---|---:|---:|---:|
| 当前 32/128、间距 2 | 0.000920 | 0.000266 | 2.892 ms |
| 近处改 128，间距 2 | 0.000419 | 0.000154 | 3.736 ms |
| 32/128，全局间距 4 | 0.000587 | 0.000161 | 2.965 ms |
| 32/128，仅近处增强滤波 | 0.000642 | 0.000191 | 2.953 ms |
| 近处 128 + 间距 4 | 0.000385 | 0.000103 | 3.915 ms |
| 强制粗档，128 条 | 0.000939 | 0.000274 | 3.042 ms |
| 强制粗档，32 条 | 0.002000 | 0.000540 | 1.903 ms |
| 全局降采样改 16 | 0.001146 | 0.000278 | 2.758 ms |
| 近处 512，高预算对照 | 0.000115* | 0.000115 | 11.151 ms |

*高预算版自身对其 32 帧均值的距离反映残余随机变化，不是零误差真值。

近处 128 的控制开销约增加 0.84 ms，换来了更明显的空间改善；近处专用滤波约增加 0.06 ms，效果较温和。512 的成本明显更高，不选作普通配置。误差距离、时间波动和模糊程度是不同指标，不把下降百分比统称为“噪声减少率”。

强制近处粗共享没有优于当前配置；降采样 16 压低了高频起伏，但对高预算对照的偏差和时间波动都未改善。因此不能把这次问题简化为继续全局加大降采样，或直接取消近处细档。

## 图一与边界

图一的当前配置与近处专用滤波原型，32 帧合计 RGB RMSE 为 `3.36e-6`，最大通道差约 `1.22e-4`。该机位大部分接收面在增强滤波范围之外，因而基本保留原画面；这不等于所有远景和所有近处物体都已验证。

扩大滤波仍可能柔化同一平面上的接触阴影和真实照明梯度；深度/法线只能保护几何边界。原型的 1.5–2.5 m 过渡与最大间距 4 只是本轮起点，还需要缓慢接近墙面、跨越质量切换距离、近处箱体接触区等运动对照。这里没有再延长时间历史来掩盖残余斑块。

GPU 是整个控制渲染命令列表的时间戳，中位数每组取 227 个有效样本，排除前 32 帧和抓图帧，不含启动烘焙与 Present；小至 0.06 ms 的单组差异不保证实际游戏中的固定收益/开销。所有序列正常退出，Release 未开启 D3D12 validation，不把零消息计数冒充 Debug GPU 检查。原始探针记录 SHA256 与上一轮一致。
