# World GI 空间滤波试验

2026-11-04，接续 [4 批次积累试验](GIDenoisingTrialReport.md)。用户实际观察指出：时间积累让斑块变化变慢，空间噪声仍存在。本轮针对单帧空间重建，已修改、编译、运行并检查图像。

## 当前采用的修改

在 `SSGI.Reconstruct` 中，为独立的 Mesh/Global world display 增加深度、法线引导的 5×5 二项式滤波，采用 **GI 像素间距 2**。Screen 原有滤波保留。两个分量分别重建后相加，再进入原来的像素时间历史和 À-trous。

几何检查使用法线一致性和双向切平面距离。棋盘格复用像素没有当前 world display 值，其 alpha 为零，必须跳过；它们不是零辐射观测。黑色且有效的 world 估计仍参与归一化，防止只平均亮样本。

过滤只影响显示与最终像素历史，**不回写 owner 的颜色缓存**，避免把空间滤波结果一轮轮扩散回共享估计。没有增加射线、延长时间历史或改探针烘焙。原来的 4 批次积累保持一致，便于隔离空间滤波效果。

`Settings/Pipeline.json` 已启用：

```json
"world_sharing": {
  "enabled": true,
  "accumulation_updates": 4,
  "spatial_filter": {
    "enabled": true,
    "step_width": 2
  }
}
```

`step_width` 可选 1、2、4；关闭 `spatial_filter.enabled` 并重启恢复本轮前的中心 world 值相加路径，时间积累另由 `accumulation_updates` 控制。省略空间滤波配置默认关闭。

本轮开始时，主配置已经是降采样 **4**，保留了该值以及 16/64 射线、DLSS Quality 等现有设置。不能沿用上一轮报告的降采样 16 来描述本轮开始的工作区。独立测试仍覆盖降采样 1、4、16。

## 对照方法

Cornell 第三机位，1280×800、AA=None、HBAO 关闭。所有空间滤波候选都保留相同的 4 批次时间积累和 world 预算 16/64。10 个静止候选、2 个运动候选，每组 291 帧，连续捕获 256–287 帧。生产开/关另用主工程可执行文件核对，Debug 另做 D3D12 validation。

本次不再把时间波动下降当成单帧降噪百分比。另观察两项：

- 固定地面区域的亮度水平二阶差分 RMS，衡量单帧空间起伏。区域是图像宽度 7%–40%、高度 72%–93%。它也包含真实光照细节，降低可能同时意味着模糊，不能直接叫“噪声降低率”。
- 降采样 4 下，每帧 RGB 对同机位 256/256 射线、32 帧均值的距离。这是带噪高预算对照，不是真值；可用于发现明显偏差，不能证明无偏。

## 开销、细节和验证边界

降采样 4/16 的 GPU 时间接近关闭版，没有从微小负差值推断加速。统计是整个 GPU 渲染命令列表，不是滤波单独耗时，不含启动烘焙/Present；每组 227 个样本，排除开头与抓图帧。没有拿它替代 2560×1600 + DLSS 的桌面帧率。

全分辨率首轮耗时波动较大：关闭/间距 2/间距 4 分别为 26.125/29.702/26.158 ms 中位数。补测关闭/间距 2 为 29.399/29.122 ms，间距 2 再测为 28.154 ms；因此不能从单组差值确认额外开销大小。

全分辨率的后两次连续抓帧还暴露了另一问题：第 260 帧起出现大范围颜色突变并逐步衰减，两次均复现；相机、烘焙 SH 与首轮相同。该段空间起伏 RMS 约 0.000495，比关闭版 0.000347 更高，不能选择性忽略。额外用主工程 Debug 正常运行到 260 帧、仅捕获一次，结果与首轮正常序列的 260 帧 RGB RMSE 为 `3.14e-6`，与异常连续序列为 `0.004625`，且 D3D12 validation 无警告/错误。这支持连续抓帧路径影响结果的怀疑，但尚未定位原因，不能据此断言生产全分辨率路径完全正常。全分辨率连续序列不作为本轮质量结论；当前启用的是已有正常对照和集成核对的降采样 4 配置。

深度、法线只能约束几何边界，不能识别同一平面上的阴影边界。接触阴影和真实光照梯度可能变柔，也不能代替世界空间的穿墙可见性检查。尤其在降采样 16 时，间距 2 的半径对应 64 个内部场景像素，图像本身已有较大的采样足迹。

主工程 Release、Debug 构建通过；降采样 4 的 Debug 实跑 259 帧，以及全分辨率的 Debug 正常单次捕获运行 263 帧，D3D12 validation 均开启，0 warning/0 error。生产开/关与对应常量试验的 RGB RMSE 分别约 `1.30e-6` / `2.90e-7`，最大差 `6.10e-5` / `3.05e-5`，不冒充逐位一致。烘焙探针记录 SHA256 保持一致。

空间滤波的配置、元数据、历史失效键已接好，C++/HLSL 常量布局以尺寸和偏移断言校验。旧的 `world_owner_spatial_filter_enabled=false` 仍正确：这次过滤的是 world display；新增的 `world_display_spatial_filter` 记录实际开关和步长。
