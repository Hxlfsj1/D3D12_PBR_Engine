# 探针方向遮挡缓存实验

2026-11-03。**实现和受控测试已完成，画质验收未通过，不替换主程序。**
`vxgi.probes.distance_visibility` 默认 `false`；正式 `Settings/Pipeline.json`
和 `x64/Debug`、`x64/Release` 主程序未被实验覆盖。

## 实现

每个探针使用 8×8 八面体方向表，每格 `uint2`，共 512 字节。复用原有
采光射线的首个命中距离和几何法线，不增加分类、采光或太阳光射线，不改变
SH、64 条采光射线或 32 次更新预算。只保存两倍探针格距内的局部遮挡信息；
更远命中视为对本地插值线段无约束。

每格保留最近采样面的径向距离、平面距离（各 FP16）和朝向远离探针的
八面体法线（16+16 bit）。运行时对每个候选贡献探针查一次表，判断查询点
是否越过缓存平面；端点接近平面时根据主射线来向区分两侧。没有正面/背面
剔除；同一墙面从两侧采样会得到相反的定向平面。未知方向拒绝贡献。
归一化平面距离容差为 0.0005，用于覆盖 FP16 舍入。这是一种有限方向
分辨率、单平面的近似，不能保证等价于实际线段与所有三角形求交。

缓存单份、按队列顺序更新。普通更新不复制整张距离表，idle 不更新。
拓扑变化时才分配新表并按稳定探针 ID 重映射，旧资源保留到对应帧完成；
分类/alpha/几何失效会清除方向数据，纯光源或材质 RGB 失效保留遮挡信息。
烘焙使用每帧槽独立的持久 SRV/UAV 描述符，运行时使用 RDG 临时 SRV。
root signature、128 字节烘焙参数和 1024 字节 SSGI 参数 ABI 不变。
描述符堆仍先于 root signature 和参数绑定。

相关源码：`Shaders/VXGIProbeDistanceCommon.hlsli`、
`Shaders/Shaders_For_VXGI_Probe_Update.hlsl`、
`Shaders/VXGIProbeRadianceCommon.hlsli`、`Passes/VXGIProbePass.h`、
`Passes/SSGIPass.h`。配置入口位于 `Resources/Settings_Manager.h`，需重启初始化。
有限帧测试通过 `Core/FiniteGPUFrameTimer.h` 导出 GPU 时间；交互运行不启用时间戳或缓存读回。

## 画质结果

最终输入和抓帧固定在 `tmp/vxgi-probe-depth/final-off`、`final-on`。
1280×800、GI 640×400、AA=None、HBAO 关闭，保留 GI 时空滤波；
近/远采样 16/64，探针格距 0.5、padding=1、Mesh SDF 格距 0.1。
下表是第 256 帧线性 filtered `E/pi` 亮度，未经过材质响应、曝光或 tone mapping。

| 用例 | 关闭缓存的平均值 | 开启缓存的平均值 | 开启缓存的最大值 |
| --- | ---: | ---: | ---: |
| B0：封闭，外灯关闭 | 0（既有对照） | 0 | 0 |
| B1：封闭，只开外灯 | 0.000168806591 | 0.000000622204 | 0.0102864761 |
| B2：后墙开孔，只开外灯 | 0.0116617220 | 0.0108319711 | 0.0857385864 |

B1 平均漏光下降 **99.6314%**，超过 1e-5 的像素由 33,406 降至 305。
但最大亮点未解决：关闭时最大值为 0.00936195，开启后为 0.01028648。
不能用平均值改善冒充“漏光归零”；raw、world gather 和 filtered 均仍有残余。
B2 平均信号为基线的 **92.8848%**，存在约 7.12% 的总信号损失。
这个比例不是正确光能保留率，也不是路径追踪误差。

B1/B2 的开关对照中，深度图和全部 96 字节原始探针记录逐字节一致。
这将差别定位在缓存可见性消费及其后续滤波，而非修改烘焙或减少采样。
最终有效探针的 64 个方向格都已填充，没有用未填满的缓存制造全黑。

![线性 GI 对照](../tmp/vxgi-probe-depth/comparison.png)

上排 B1，标尺白色≥0.001；下排 B2，白色≥0.04。
每行左右使用相同标尺，行之间标尺不同。已实际查看生成的 GI 抓帧与该对照图。

烘焙检查独立通过：封闭太阳组室内 440 个有效探针全部 SH=0；
开孔太阳组 440 个中 423 个非零。两组完整原始探针记录与先前保留的
太阳遮挡自命中过滤版本逐字节一致。该小修保持有效。

早期实验仅保存在 `on`、`off`、`moments-v1`、`minimum-v2`、`plane-v3` 中：
仅用均值/方差仍有明显漏光；收紧最小径向距离可使本测试封闭盒归零，
却把开孔盒平均 GI 压到约 53%。这些结果没有混入最终验收。

## GPU 时间与内存

最终 Release 使用原开口 Cornell + Plain、固定 corner 相机、正常合成输出，
仍为 1280×800、AA=None、HBAO 关闭，其余探针与世界采样设置同上。
每次完成 259 帧，排除前 32 帧和保存帧，各保留 226 个 GPU 时间戳样本。
计时覆盖整帧命令列表（含 ImGui），不包含 Present 等待；启动烘焙不在统计内。

| 方向缓存 | GPU 中位耗时 | P95 | 距离缓存 |
| --- | ---: | ---: | ---: |
| 关闭 | 10.179456 ms | 11.714264 ms | 0 |
| 开启 | 11.115568 ms | 12.709512 ms | 55,559,168 B |

本组增加 **0.936112 ms（9.1961%）**。108,514 个探针额外使用约 **52.99 MiB**；
拓扑重映射时新旧表可短暂同时存在，未计入上述稳定状态值。
没有重测用户现场的 2560×1600 DLSS Quality 视角，不宣称恢复 60 FPS，
也不从隐藏进程耗时推算 FPS。

## 验证与结论

- 独立 Debug/Release 构建和 UI 架构检查通过，既有编译器/第三方 PDB 警告保留。
- 最终九次运行完整退出，D3D12 warning/error 为零。七次 Debug 验证层可用；
  两次 Release 未启用验证层，不能把其零计数当作验证层检查。
- B0/B1/B2、两组太阳控制、两组关闭缓存对照与两组 Release 原场景运行均确认
  探针完成 32 次采集，没有未分类或采集失败。最终 shader、程序和 Pipeline 哈希有记录。
- 开关缓存的模型、相机、深度与原始 SH 对照通过；方向表数据有限、范围有效。
- 动态物体/材质 alpha 编辑、方向表重映射、低射线预算和其他薄片几何尚未运行专项验证。

收尾另完成三次兼容性运行（`compatible/runs`）：烘焙 shader 同时将旧可执行文件
预留参数的 `0` 和新程序的 `UINT_MAX` 视为缓存关闭。原 `x64/Debug` 主程序
实际完成封闭太阳组，验证层零 warning/error、原始 SH 与保留的小修版本一致。
当前 shader 的 B1/B2 重跑中，原始 SH、方向表、深度/法线、BounceSource、
world gather 和 owner atlas 均与冻结测试逐字节一致。B1 所有纹理也一致；
B2 的屏幕/滤波输出存在重跑差异，filtered 最大绝对差为 0.00024414、
平均绝对差为 5.34e-8；未声称所有最终纹理逐字节相同。
冻结的性能输入保持原版本，不把这三次正确性检查混入时间戳样本。
共十二次完整运行的 D3D12 warning/error 均为零。

**不推广为默认修复。** 当前版本证明了缓存可以把本测试中的大部分跨墙贡献
以较小的 GPU 成本压下去；残余最大亮点及正常信号损失仍未达标。
单格平面无法完整表达一个方向区域内的多层或多面遮挡，剩余误差还需独立定位，
不能直接靠扩大偏移或继续压低 `tMin` 解决。

机器数据：`tmp/vxgi-probe-depth/analysis.json`；最终运行记录在两个
`final-*/runs` 目录。分析命令：`python Tests/AnalyzeVXGIProbeDistance.py`。
运行器支持 `-ExecutablePath tmp/vxgi-probe-depth/bin/Debug/LearnDirectX.exe`，
用于在完整隔离的目录中复现，主程序保持可用。
