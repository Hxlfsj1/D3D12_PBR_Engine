# GI 时间降噪：相关样本的方差修正

2026-11-03。**已撤回**。用户实测反馈改善甚少，要求撤回。
本次新增的钳制/重置逻辑、常量、配置开关、历史键及抓帧字段已移除，
恢复此前的降噪路径；保留三角形确认和此前其他GI修改。本次撤回未编译或运行。
以下仅为已撤回实验的历史记录，其中开关与实现说明不再代表当前源码。

用户反馈当前GI噪声不可接受，并要求修正采样/时域累积链路。现有STBN射线方向、
重投影、16次慢历史上限、7次快历史窗口，以及25点邻域均保留。
此前31次慢历史试验已有运动观感负反馈，本轮没有重新采用。

## 源码依据

现有历史钳制从5×5邻域统计快历史的颜色方差，噪声重置从同一邻域统计当前输入方差。
World owner共享、粗档重建、屏幕重建和缓存复用都会造成邻域相关。
若邻居重复同一估计，空间方差可以接近零，但该估计本身仍可能逐帧波动。
此时钳制盒可能收缩到快历史附近，随机波动也可能被判成需要重置历史的变化。
这是代码层面可构造的退化情形，尚未用用户场景抓帧证明它是全部噪声的来源。

现有fast历史的alpha存储与slow RGB对应的亮度二阶矩；它本来就用于空间滤波方差。
这次复用已有数据，而非再加一套随机数或纹理。

## 修改

1. 用 `max(E[L²] - E[L]², 0)` 得到中心的时间亮度方差；均值和二阶矩保持同一
   `RelaxLuminance` 基底，不把它直接当成YCoCg的Y方差。
2. 用快历史窗口（实际历史长度与7的较小值）缩放方差，构造快估计的保守亮度区间。
   该窗口是工程近似，不是相关缓存样本的精确有效样本数。
3. 保留原空间颜色盒；若时间区间允许保留更多slow历史，只沿原钳制结果到slow历史
   的线段放宽，不额外收紧空间盒。短历史≤3仍沿用原逻辑。
4. 噪声感知重置采用当前输入空间sigma与单次观测时间sigma的较大值，避免仅因
   空间样本相关就将随机波动当成确定的光照变化。重置和历史加速机制仍保留。
5. 输出继续使用原二阶矩修正；不把重用帧当新观测，不改变样本标记、更新频率、
   射线数、下采样、空间滤波半径或场景曝光。

历史钳制常量利用原padding传递两个float，大小仍为64字节，不新增GPU纹理或邻域读取。
新增算术的实际GPU成本未测量。此修改不能替代缺失的几何信息，也没有修复所有
屏幕空间缺失、SDF误命中、SH取光或运动物体重投影问题。

## 开关与边界

`Settings/Pipeline.json`：

```json
"ssgi": {
  "denoising": {
    "temporal_variance_clamp": true
  }
}
```

设为false并重启可回到此次修改前的钳制规则。设置已纳入历史失效键和抓帧元数据。
几何拒绝、短历史保护、快历史、原光照变化响应参数都保留，但时间不确定性放宽
可能延缓部分变化的响应，因此需要用户观察静止噪声与移动/变光拖影之间的取舍。
没有把这次局部改造称为完整NRD，也没有将历史参考验证算作本次验证。

源码：`Shaders/Shaders_For_SSGI_Temporal.hlsl`、
`ThirdParty/NVIDIA/NRD/RelaxDiffuse.hlsli`、`Passes/SSGIPass.h`。
